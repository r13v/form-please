# Localization

Form, Please has no locale setting. Each part of the form gets its text from
a different source:

- Field labels and other definition text come from your definition. Read the
  locale from the runtime `context`.
- Validation messages come from the schema library. Configure its messages.
- Array action labels and the file button label come from the slots and
  controls of the form kit. Give the kit an `i18n` object.

## Translate labels with context

Put the locale in the kit context. A label function gets the `context` in its
second argument. When you give `useForm` a new `context` object, Form, Please
resolves the labels again. Memoize the object, so that it changes only when the
locale changes.


A custom control gets the same `context` in its props, so it can read
`context.locale`. Read [Resolver values](/definitions#resolver-values) for the
arguments of property functions.

## Translate validation messages

Form, Please displays the messages that the Standard Schema returns. Configure
the schema library once, before form validation runs. Do not configure it
during a component render, because the configuration is global.

A message that you give to one schema or one check has priority over the
global messages.

## Translate the form kit labels

The default slots and the Material UI preset use different `i18n` key names
for the same actions. Their callbacks also get different arguments.

| Label | `createDefaultSlots` key | `createMuiFormKit` key | English default |
| --- | --- | --- | --- |
| Append an array item | `arrayAdd` | `addItem` | Add item |
| Remove an array item | `arrayRemove` | `removeItem` | Remove item 1 |
| Move an array item up | `arrayMoveUp` | `moveItemUp` | Move item 1 up |
| Move an array item down | `arrayMoveDown` | `moveItemDown` | Move item 1 down |
| Choose a file | — | `chooseFile` | Choose file |

- A `createDefaultSlots` value is a string or a callback. The `arrayAdd`
  callback gets the array `label`. The item callbacks get the zero-based
  `index` and the one-based `position`.
- A `createMuiFormKit` value for an item action is a callback that gets the
  one-based position as a number. `addItem` and `chooseFile` are strings.
- All keys are optional. A missing key keeps the English default.
