# Get started

Build and submit a working form in three steps. This example uses the native
preset, Zod, and the default validation timing.

## Install

Install Form, Please, React Hook Form, and a Standard Schema library. This
example uses Zod.

:::code-group

```sh [npm]
npm install form-please react-hook-form zod
```

```sh [pnpm]
pnpm add form-please react-hook-form zod
```

```sh [yarn]
yarn add form-please react-hook-form zod
```

```sh [bun]
bun add form-please react-hook-form zod
```

:::

React 18 and React 19 are supported peer dependencies.

:::steps


`kit.AutoForm` renders the native `<form>`, an error summary, and the generated
fields. Add `kit.Submit` as a child to render the submit button.

After a valid submit, `value` contains the schema output, including `slug`.
The `onSubmit` callback keeps `value` in React state, and the `<pre>` element
shows it. Use the `input` callback property when you also need the schema
input.

All JavaScript package entries are React client modules. In a Next.js App
Router project, put `"use client"` at the start of the component file.

## Add the optional layout

Import the optional structural stylesheet once if you want baseline spacing:

```ts
import "form-please/layout.css"
```

The native preset is intentionally unstyled. Replace it with your own controls
and slots, or use the Material UI preset.

## Try more features

Open the [playground](/playground). Edit a definition in the browser and see
the form, the output, and the TypeScript errors change. Its scenarios show a
transform, conditional fields, an array, and a mistyped path.
