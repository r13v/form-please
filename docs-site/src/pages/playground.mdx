# Playground

Edit the code. The form re-renders after each pause in typing. Submit it to
see the validated output. The editor is the one from VS Code, with the full
TypeScript language service: completions, signature help, hover types, and
errors as you type.

<LivePlayground />

## How it works

- The editor contents are compiled with Sucrase in your browser. Nothing is
  sent to a server.
- The compiled module receives the real `form-please` package, `react`, and
  `zod`. The rendered form is the same code path an application uses.
- The editor is Monaco, the editor component of VS Code, with the TypeScript
  language service running in a web worker over the package declaration files.
  It downloads once per visit and starts while you read this page.

## Limits

- Only the imports listed under the preview are available. Other packages and
  relative files cannot be resolved.
- The Material UI preset is not loaded here. See the
  [Material UI example](/examples/mui-yup) for a live version.
- Edits are not saved. Copy the code out before you leave the page.
