# Research grant application

The form changes shape for individual and collective applicants. It also
changes the settlement and reporting fields for the selected routes.

## Try the complete flow

Choose a collective and the registered representation path. Search the fake
registry and apply a result with typed `form.api` updates. Change the payout
route to resolve another conditional branch.

<ResearchGrantDemo />

## What this form demonstrates

- Conditional fields across several nested objects.
- An application-owned registry search inside the form.
- Read-only values populated through `form.api.setValue`.
- `useWatch` for conditional application UI and a live preview.
- Two sequential mutations from transformed schema output.
- Preserved values when the selected branch changes.
