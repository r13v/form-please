# Campaign builder

Seven campaign templates share an audience, schedule, and channel model. The
schema is a discriminated union, so each template has its own fields and
messages.

## Try the complete flow

Switch between the loaded draft and a new campaign. Change the template to see
the definition resolve a different section. Paid templates also show amount,
currency, and recurring interval fields.

<CampaignBuilderDemo />

## What this form demonstrates

- A discriminated union with seven template variants. One section shows the
  fields of each variant.
- A nested payment union for free, fixed or flexible, and recurring payments.
- A starting draft for each template. Each select and checkbox has a value
  when its section appears.
- Context-provided audience options.
- Separate create and update mutations outside form state.
- `form.api.watch()` for the live campaign preview.
- Transformed submit output with a derived channel list.
- Preserved values when a conditional section becomes hidden. The output
  contains only the selected template.
