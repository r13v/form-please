# Идеи по улучшению

Здесь остаются только отложенные продуктовые направления, которые требуют
отдельного решения.

## Публичный API и DX

- **Сообщать состояние загрузки `options`.** Приложению полезно отличать пустую
  коллекцию от текущего запроса. Минимальный вариант — передавать option-capable
  контролу отдельный булев признак рядом с коллекцией, не добавляя кеширование,
  retry, search или pagination. Это намеренно отложенное изменение публичного
  контракта: перед реализацией нужно пересмотреть принятое в ADR 0022 решение не
  предоставлять loading UI для асинхронных опций.
